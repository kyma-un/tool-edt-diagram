Interacción

  • Haz clic en un nodo para seleccionarlo.
  • Doble clic para expandir o colapsar sus hijos.
  • Usa la rueda del mouse para hacer zoom.
  • Arrastra el lienzo para desplazarte.
  • Expandir rama: abre todo el subárbol del nodo seleccionado.
  • Colapsar rama: cierra todo el subárbol del nodo seleccionado.
  • Búsqueda: escribe y pulsa Enter; expande el camino y centra el nodo.
